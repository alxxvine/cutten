# 🐾 Полянка котиков

Уютная браузерная игра про то, как узнаёшь котиков. По полянке гуляют котики, и все они разные:
кто-то сам идёт обниматься, кто-то боится резких движений, а кому-то не до ласки — он хочет играть.
Поймёшь каждого — котики начнут тебе доверять и останутся жить на полянке.

**Играть:** https://alxxvine.github.io/cutten/

## Как играть

- 😽 **Ласковый** сам идёт навстречу — води ладошкой по спинке, чешет только движущаяся рука.
- 🙀 **Пугливый** боится резких движений. Подойди медленно и **замри** рядом — он принюхается к руке
  сам, а потом можно гладить, только мягко.
- 🧶 **Игривому** не до ласки. Поводи лапкой рядом — он погонится, вот это ему и нужно.
- 💗 За понимание растёт доверие: 5 сердечек на котика. На трёх котик остаётся жить на полянке
  и встречает тебя, когда возвращаешься, на пяти — приводит друга.
- 🌼 Проиграть нельзя, таймеров и штрафов нет. Не понял котика — просто попробуй иначе.

Котики всё показывают телом: хвост трубой — рад, уши прижаты — страшно, глаза щёлочками — блаженство,
пунктир вокруг — напрягся. Этому нигде не учат текстом, но именно в этом вся игра.

Работает мышкой и пальцем. Свои котики и мурчалки сохраняются в браузере.

## Что внутри

Ноль зависимостей, ноль сборки, ноль внешних ассетов — три файла:

| Файл | Что делает |
| --- | --- |
| `index.html` | Разметка: canvas, HUD, стартовый экран и экран помощи |
| `style.css` | Пастельная тема, адаптив под мобильные |
| `game.js` | Вся игра: котики, частицы, звук, игровой цикл |

Котики рисуются процедурно на `<canvas>`: случайные окрасы (полосатый, пятнистый, смокинг),
хвост-пружинка, моргание, подёргивание ушей, прищур от удовольствия, прижатые уши от испуга.
Звук — WebAudio без файлов: мурчание, «мяу», «мрр?» и шипение синтезируются на лету.

Замысел игры и планы на следующие версии — в [DESIGN.md](DESIGN.md).

## Запуск локально

```bash
git clone https://github.com/alxxvine/cutten.git
cd cutten
python3 -m http.server 8000
# открыть http://localhost:8000
```

Можно и просто открыть `index.html` в браузере — сборка не нужна.
