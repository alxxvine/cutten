# 🐾 Полянка котиков

Милая браузерная игра: по полянке бегают котики, иногда садятся и просят, чтобы их погладили.
Наводи ладошку и чеши — котик замурчит.

**Играть:** https://alxxvine.github.io/cutten/

## Как играть

- 👋 Наведи ладошку на котика и **води туда-сюда** — чешет только движущаяся рука.
- 💗 Заполни сердечко до конца — котик замурчит и подарит «мурчалки» (очки).
- 🙀 Котики с сердечком над головой ждут ласки, у них ограниченное терпение. Не успел — котик грустит,
  и счастье полянки падает.
- 🔥 Гладь котиков подряд без больших пауз — растёт множитель (до x5).
- 🌼 Проиграть нельзя. Это полянка, тут просто хорошо.

Работает мышкой и пальцем. Рекорд сохраняется в браузере.

## Что внутри

Ноль зависимостей, ноль сборки, ноль внешних ассетов — три файла:

| Файл | Что делает |
| --- | --- |
| `index.html` | Разметка: canvas, HUD, стартовый экран и экран помощи |
| `style.css` | Пастельная тема, адаптив под мобильные |
| `game.js` | Вся игра: котики, частицы, звук, игровой цикл |

Котики рисуются процедурно на `<canvas>`: случайные окрасы (полосатый, пятнистый, смокинг),
хвост-пружинка, моргание, подёргивание ушей, прищур от удовольствия. Звук — WebAudio без файлов:
мурчание, «мяу» и звоночек синтезируются на лету.

## Запуск локально

```bash
git clone https://github.com/alxxvine/cutten.git
cd cutten
python3 -m http.server 8000
# открыть http://localhost:8000
```

Можно и просто открыть `index.html` в браузере — сборка не нужна.
